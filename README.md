# XNXNV - Solusi Digital Berkualitas

Website resmi XNXNV, perusahaan teknologi digital yang menyediakan solusi lengkap untuk bisnis modern.

## Tech Stack

- **Framework**: Next.js 16.3.0
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **UI Components**: Custom React components

## Features

- Responsive design
- Dark mode support
- SEO optimized
- Fast page transitions
- Modern UI/UX

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
